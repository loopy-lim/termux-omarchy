# Y900 13 태블릿 화면·Mac 키보드 프로필

2026-10-06. 대상은 ADB `Y900`, Lenovo `TB522FU`이며 다른 장치에는 적용하지 않는다.

## 구현

- Android Surface의 기본 프레임버퍼를 최대 가로 1920×1280, 세로 1280×1920으로 맞춘다.
  종횡비를 유지하며 작은 화면은 확대하지 않는다. 원본 해상도 옵션과 별도 UI 배율을 제공한다.
  Android 전체 해상도·밀도는 바꾸지 않는다. 처리 픽셀 수 감소는 계산상 근거이며 체감 속도 향상은
  이번 APK를 설치한 실제 장치에서 확인해야 한다.
- 포인터는 물리 View 좌표에서 움직이고 Linux 전달 시 프레임버퍼 좌표로 변환한다.
  절대 좌표, 캡처된 상대 이동, 스크롤, 버튼 해제 모두 같은 경로를 사용한다.
- 화면 모서리·카메라 영역을 WindowInsets로 피한다. Y900에서 보고된 둥근 모서리 반경은 33px이다.
  네이티브 설정 패널은 최대 560dp 폭, 긴 스크롤 패널은 최대 720dp 높이로 제한한다.
  원격 연결·GPU 검사 같은 보조 창은 640×480의 떠 있는 창으로 시작한다.
- 설정의 Mac 배열을 켜면 물리 Alt가 Cmd, 물리 Meta가 Option이다. Ctrl·Fn 위치는 유지한다.
  Fn의 별도 이벤트 전달과 위치 교환은 키보드 펌웨어의 지원에 달려 있다.
- Cmd+C/V/X/A/Z, Shift+Cmd+Z, 저장·열기·탭·찾기·주소·새로고침·인쇄·닫기 등은
  Linux 앱의 해당 단축키로 전달한다. 터미널 Cmd+C/V는 Ctrl+Shift+C/V이며 물리 Ctrl+C는
  실행 중단으로 유지한다. 방향키·단어 이동·Shift 선택도 처리한다. 앱별 Cmd+B·숫자 등은
  균형 잡힌 Ctrl 조합으로 전달한다. 앱이 해당 기능을 제공해야 한다.
- 현재 장치의 저장된 KeyBridge 프로필을 기준으로 Caps 탭 언어 전환, Caps+H/J/K/L,
  Shift 선택, Caps+1…0/-/=의 F1…F12, Caps+D/F의 작업 공간 이동을 구현한다.
  이미 KeyBridge가 변환한 F13/F14 및 언어 전환 키도 처리한다. 다른 앱의 KeyBridge 설정은 수정하지 않는다.

## 검증 경계

원래 설치 APK의 SHA-256은 `88303384ee1353f922d2a96f29eeeab916ca65291b0135844122fe89b54c5ba0`이다.
사용자는 이 APK에서 터미널 입력과 트랙패드 클릭이 정상이라고 확인했다.

새 후보의 소스·빌드·루트 파일 시스템·호스트 검사 증거는
`docs/validation/2026-10-06-y900-tablet-fit/`에 기록한다. 설치 승인/작업 저장 확인 전에는
새 후보를 실물에서 통과했다고 표시하지 않는다. 기존 Linux HOME과 KeyBridge 설정은 보존한다.

원래 APK의 실제 앱 UID에서 Adreno 830 VirGL 오프스크린 픽셀 검사는 통과했으나,
GTK OpenGL 창은 renderer 연결 상실로 종료 코드 134를 반환했다. GPU 창 표시 및
전체 데스크톱 GPU 가속을 통과한 것으로 간주하지 않는다. 기본 nested Sway는 pixman을 사용한다.

## 실제 장치 확인

1. 미저장 Linux 작업을 저장한 후 업데이트 설치하고 데스크톱을 연다.
2. 설정에서 Mac 배열을 켜고 원본 해상도 옵션을 끈다.
3. 출력 크기·화면 여백·설정 패널·원격 보조 창을 확인한다.
4. 물리 Alt+C/V, Alt+Z, Alt+Shift+Z, Alt+Enter와 Caps 조합을 확인한다.
5. 터미널 Cmd 복사·붙여넣기와 Ctrl+C 중단을 각각 확인한다.
6. 마우스/트랙패드의 끝점·클릭·스크롤, 연결 해제 후 눌린 키의 해제를 확인한다.
7. 입력 지연·스크롤·창 조작의 체감 성능을 확인한다. 이전 VM 통과는 이 확인을 대신하지 않는다.
