# Changelog

## 0.1.0-alpha.1 — initial source alpha

- Publish the maintained Termux Omarchy runtime and portable workflow sources.
- Preserve the input handoff, trackpad scroll/lifecycle and touchscreen-only zoom changes as reviewable source and historical patch tools.
- Include source inventories, fail-closed installation/build preflight, host regressions and CI.
- Provide English documentation by default with Korean README, installation and development companions.
- Retain applicable GPL, MIT and BSD notices and distinguish copied source from unbundled runtime dependencies.

This release contains source only. Complete fresh-device installation, clean modified-APK reconstruction, binary corresponding-source closure, sustained FPS/latency measurements and long-duration acceptance remain open. Existing-device observations are documented separately in [the validation scope](docs/VALIDATION.md).
